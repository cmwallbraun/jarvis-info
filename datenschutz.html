Datenschutzerklärung

Jarvis ist eine private Anwendung von Conrad Wallbraun und nur für das eigene Google-Konto bestimmt.

Jarvis liest Gmail und Google Kalender dieses Kontos nur lesend, um dem Inhaber Zusammenfassungen und Erinnerungen anzuzeigen. Die Daten werden nicht verkauft, nicht zu Werbezwecken genutzt und nicht an Dritte weitergegeben. Zur Erstellung von Antworten können Ausschnitte an den vom Inhaber genutzten KI-Dienst Claude von Anthropic übertragen werden.

Die Nutzung der über Google-APIs erhaltenen Daten entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung.
